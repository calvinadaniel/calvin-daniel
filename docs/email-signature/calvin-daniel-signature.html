Install in Titan

  1. Deploy the new icon files to the site first (images/email-icon-globe.png, images/email-icon-linkedin.png).
  2. Open Titan Webmail → Settings (gear) → Preferences → Signatures.
  3. Click Add Signature (or edit the existing one), then Edit as HTML.
  4. Paste the copied HTML, Save, and send yourself a test.
