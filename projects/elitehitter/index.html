EliteHitter+

MLB Advanced Stat Explorer  ·  Proof of Concept

Demo

Inspiration

Baseball has always been a passion — especially the analytical side. As an avid fantasy baseball player, I'm constantly digging into advanced stats looking for an edge on the competition. That habit of turning raw data into a competitive advantage is what sparked this project.

The Goal

EliteHitter+ is a proof of concept: Can I build something credible in the baseball analytics space? The core idea is to explore new ways to assess hitter performance beyond traditional stats — starting with HardContact+, a custom metric defined as Hard Hit% − Whiff%, pulling directly from Baseball Savant's Statcast data.

Tech Stack

React 18 Node.js Express Tailwind CSS Vite Baseball Savant Statcast API
