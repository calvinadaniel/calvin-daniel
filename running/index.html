Where Running Meets Data

Built a Tool to Chase Boston

Qualifying for the Boston Marathon is the goal that's been driving my training for the past year. Somewhere between spreadsheets of splits and a growing Strava history, my two obsessions collided — so I built a dashboard that pulls my run data, tracks pace trends over time, and forecasts the race where my qualifying time actually lands. It's the same instinct behind everything I build: turn raw data into a plan you can act on.
